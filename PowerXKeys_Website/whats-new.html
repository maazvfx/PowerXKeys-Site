v5.3.0

What's New

Zero input lag, mobile remote control, sleek visual timelines, and a completely redesigned macro block architecture.

Remote Mouse/Keyboard & Mobile Soundboard

The Mobile Remote is now a fully featured wireless control station. Take command of your PC straight from your phone with real-time screen feeds and customized action buttons.

  • Real-time trackpad gestures including double-tap-to-drag and two-finger vertical scrolling.
  • Custom mobile soundboard syncing (WAV/MP3 audio up to 5MB, customizable grid cards).
  • PIN code protection, sound alerts when devices connect, and secure internet connections.

Sleek Timeline & Inline Editing

The Macro Timeline has been completely redesigned with a gorgeous, dark aesthetic that minimizes clutter with a cleaner, more consistent design.

  • Rename any step by simply double-clicking it in the timeline.
  • Cleaner input fields and file-picker buttons that appear when you hover.
  • Reorder steps with Ctrl+Up/Down and drag to select multiple steps at once.

Smart View Optimization & Delay Merging

Recorded macros are now automatically cleaned up for maximum readability without erasing raw data.

  • Combines back-to-back pauses and typing into simpler steps.
  • Groups keyboard shortcuts (like Ctrl+C) into single readable steps.
  • The original recording is always kept in Raw View for advanced users who need exact timing.

Call Macro (Sub-Macros)

Organize complex automations by linking your macros together. One macro can now call and run another macro, turning your library into a modular toolkit.

  • Chain macros together so a single hotkey triggers an entire multi-step workflow.
  • Reuse common routines (like a login sequence) across multiple macros without duplicating steps.
  • Built-in safety limits automatically prevent infinite loops if macros accidentally call each other.

What's Next? ROADMAP

We are currently designing and building deep, native integration profiles to let you automate operating systems and professional software directly:

  • System Automation: Native Windows-level window tiling and desktop environment control.
  • Excel Automation: Pro-grade data entry, cell formatting, and spreadsheet automation templates.
  • Chrome Automation Suite: Advanced tab management, browser automation, and productivity hooks.
  • Creative Profiles: Dedicated timeline control scripts for Adobe Premiere Pro and CapCut Pro.
